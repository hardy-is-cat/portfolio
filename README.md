# ZUAL'S PORTFOLIO

## 내용

`Next.js`와 `TailwindCSS` 등을 이용해 만든 포트폴리오입니다.
개발자로서의 저와 일반인으로서의 저를 다크모드, 라이트모드로 전환할 수 있게 하였습니다.
반응형으로 만들어졌습니다.

## 사용한 기술

- TypeScript
- React
- Next.js(App Router)
- TailwindCSS
- Motion
- Zotai
